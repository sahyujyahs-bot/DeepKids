# Layer artwork

One folder per card, named by its code. The paths in `cards.json`
point here, so a file's name has to match exactly what the studio
recorded.

```
ar/layers/sci1002/IMG_6193.png
```

Until a file is here the studio shows that layer as a pink outline and
the AR page draws nothing for it. Nothing else breaks.

**Size matters more than usual.** These download onto a phone with the
camera already running. Export at the size the art needs and no more,
and prefer WebP to PNG where there is no transparency to lose — a
2388x1668 PNG is several megabytes, and the same frame as WebP is
usually under 300KB.
