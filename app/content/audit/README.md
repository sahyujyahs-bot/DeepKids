# Board depth audit (science, classes 1 to 5)
- `board-points-science-1-5.json`: every learning point from Cambridge, NCERT (real books), ICSE, NIOS (real books), Edexcel, IB PYP, Singapore.
- `board-judged-science-1-5.json`: each point judged against our units: COVERED, THIN (unit touches it, `add` says what to add), PLANNED (planned unit would cover it), MISSING.
- Judged by Haiku with a text check in the unit files. Some NIOS Level B and IB sources are partial or old. About 100 points are social, craft or dated and are marked in `add`.
