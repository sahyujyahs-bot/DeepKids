R261: 🔬 Science Experiments as Gameplay Types
R262: 1. Predict–Test–Observe (Core Experiment Play)
R263: Setup → ask kid to predict outcome.
R264: Run experiment → compare result.
R265: Example: Drop a feather vs a ball → which lands first?
R266: 👉 This is the “Guess & Reveal” mechanic, same as drawing a mystery card, but in real world.
R267: 2. Variable-Changing Experiments (Rule Variation Play)
R268: Repeat with 1 change (height, size, material).
R269: Kids compare results.
R271: Example: Bounce different balls from same height → which bounces higher?
R272: 👉 Same structure as “tweak rules in a board game” → teaches systems thinking.
R273: 3. Cause & Effect Chains (Experiment as Domino)
R275: One event triggers another.
R277: Example: Vinegar + baking soda → gas → blows up balloon.
R279: Treat as chain-reaction game (like Rube Goldberg).
R280: 👉 Mechanic = “Trigger something and see cascade.”
R281: 4. Exploration Experiments (Discovery Play)
R283: Open-ended, no set “right” answer.
R285: Example: Shine flashlight on objects → what shadows/shapes appear?
R287: Mechanic = Exploration / Mapping.
R288: 5. Competition Experiments (Challenge Play)
R290: Time it, measure it, race it.
R292: Example: Whose paper airplane flies farthest?
R294: Mechanic = Sports overlay on science.
R295: 6. Simulation Experiments (Model Play)
R297: Use simple objects to model big systems.
R299: Example: Bed sheet + balls → spacetime curvature.
R301: Mechanic = Roleplay but with objects.
