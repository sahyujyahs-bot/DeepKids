# Number patterns: what comes next?
`math.patterns.number-patterns.L1`

**Summary.** A staircase of chana has 1, then 2, then 3, then 4. How many will the seventh step have? You can know before you build it. You will build staircases, hop along a number track, put down kolam dots and say a chant that grows. You will learn to find the rule of a number pattern, carry it on, run it backwards and find a missing number. You will also see how far one small step can take you.

**Intro.** *How many dots will step 5 have?* Step 5 will have 5 dots. Each step has one more dot than the step before. That is the rule of this pattern. When you know the rule, you can say what comes next without seeing it. In this unit you will find the rules of number patterns with chana, hops and claps.

## Learning outcomes
0. I can carry on a number pattern that goes up by one or by two each time.
1. I can carry on a number pattern that goes down by one or by two each time.
2. I can say the rule of a pattern: what changes each time.
3. I can find a missing number or a wrong number in a pattern.
4. I can build a number pattern as a staircase and show it on a number track.
5. I can tell whether a pattern grows, shrinks or repeats.

## Terms
- **Number pattern**: A row of numbers that follows a rule. *e.g.* 2, 4, 6, 8 is a number pattern. Each number is two more than the one before.
- **Rule**: What you do each time to get the next number. *e.g.* In 1, 2, 3, 4 the rule is one more each time.
- **Step**: How much the pattern changes each time. It is the size of the jump. *e.g.* In 3, 5, 7 the step is two. You jump over one number each time.
- **Growing pattern**: A pattern where the numbers get bigger each time. *e.g.* 5, 6, 7, 8 grows by one each time.
- **Shrinking pattern**: A pattern where the numbers get smaller each time. *e.g.* 10, 8, 6, 4 shrinks by two each time. There are two fewer each time.
- **One more, one fewer**: One more is the next number when you count on. One fewer is the number just before. *e.g.* One more than 6 is 7. One fewer than 6 is 5.
- **Staircase**: Rows of things laid one under the other, where each row is longer or shorter by the same amount. *e.g.* Rows of 1, 2, 3 and 4 chana make a staircase that grows by one.
- **Number track**: A strip of boxes with the numbers written in order, one in each box. *e.g.* You put a button on 0 and hop it two boxes at a time: 2, 4, 6.
- **Missing number**: A number left out of a pattern. The rule tells you what it is. *e.g.* In 4, 5, __, 7 the missing number is 6.

## Explanations
### A number pattern has a rule · *defined*
**Definition:** A number pattern is a row of numbers that follows a rule. The rule says what to do each time to get the next number.

Look at the rows of dots: 1, 2, 3, 4. Each row has one more dot than the row above. 'One more each time' is the rule. A rule needs a start too. This pattern starts at 1. If you know the start and the rule, you can make the whole pattern yourself. Try it: start at 5, one more each time. You get 5, 6, 7, 8.
- e.g. Start at 1, one more each time: 1, 2, 3, 4, 5.
- e.g. Start at 2, two more each time: 2, 4, 6, 8.
- e.g. Start at 10, one fewer each time: 10, 9, 8, 7.
### One more each time · *defined*
**Definition:** In a 'one more' pattern, each number is the next counting number.

Here is a worked example. The pattern is 6, 7, 8. What comes next? One more than 8 is 9, so 9 comes next. A 'one more' pattern can start anywhere. Counting itself is this pattern: 1, 2, 3, 4, and on for ever. Now you try: 12, 13, 14. What comes next?
- e.g. The stairs in a house: each stair is one more than the last.
- e.g. Your age: one more each birthday.
- e.g. 13, 14, 15, 16: one more each time, starting at 13.
### Two more each time · *defined*
**Definition:** In a 'two more' pattern, each number is two more than the one before. You jump over one number each time.

Here is a worked example. Put a button on 2 on the number track and hop two boxes. You land on 4, then 6, then 8. The pattern is 2, 4, 6, 8, and you jumped over 3, 5 and 7. Now start on 1 with the same rule. You get 1, 3, 5, 7. The rule is the same, but the start is different, so the numbers are different.
- e.g. Shoes by the door: 2, 4, 6, 8, one pair at a time.
- e.g. The right-hand pages of most books: 1, 3, 5, 7.
- e.g. Climbing stairs two at a time: you land on 2, 4, 6.
### Shrinking patterns: one fewer, two fewer · *defined*
**Definition:** In a shrinking pattern, each number is smaller than the one before, by the same amount each time.

Here is a worked example. Five idlis are on a plate, and you eat one at a time. The pattern is 5, 4, 3, 2, 1, 0. The rule is one fewer each time. A pattern can also go down in twos: 10, 8, 6, 4, 2, 0. With chana, a shrinking pattern stops when nothing is left. A shrinking pattern is a growing pattern read from the other end. Read 5, 4, 3 backwards and you get 3, 4, 5.
- e.g. A countdown: 5, 4, 3, 2, 1, zero.
- e.g. A lift going down: 4, 3, 2, 1.
- e.g. Twelve murukkus, two eaten each day: 12, 10, 8, 6.
### How to find the rule · *defined*
**Definition:** To find the rule, look at two numbers side by side. Ask: did it go up or down, and by how much? Then check another pair, because one pair alone can trick you.

Here is a worked example. The pattern is 3, 5, 7, 9. Step 1: is it going up or down? It is going up. Step 2: how far is it from 3 to 5? Hop it on the number track: two hops. Step 3: check the other pairs. From 5 to 7 is two, and from 7 to 9 is two, so the rule is two more each time.
- e.g. 8, 9, 10: up by one each time. The rule is one more.
- e.g. 14, 12, 10: down by two each time. The rule is two fewer.
- e.g. 1, 2, 4: up by one, then up by two. The step is not the same, so the rule is not 'one more'.
### Finding a missing number or a wrong number · *defined*
**Definition:** A missing number is found by using the rule from the number before it. A wrong number is found the same way: say the pattern by the rule, and stop where the written number does not match.

Here is a worked example. The pattern is 4, 6, __, 10. Step 1: find the rule from two numbers side by side. From 4 to 6 is two more. Step 2: use the rule. Two more than 6 is 8. Step 3: check with the next number. Two more than 8 is 10, so 8 fits.
- e.g. 7, 8, __, 10: the missing number is 9.
- e.g. 9, 7, __, 3: the rule is two fewer, so the missing number is 5.
- e.g. 2, 4, 5, 8: the 5 is wrong. Two more than 4 is 6.
### Growing, shrinking or repeating? · *defined*
**Definition:** A repeating pattern has a part that comes again and again. A growing pattern gets bigger each time. A shrinking pattern gets smaller each time.

Clap, stamp, clap, stamp is a repeating pattern. The part 'clap, stamp' comes again and again, and it never gets bigger. Now clap once, then twice, then three times. That is a growing pattern, because each turn is one clap more. To tell them apart, ask one question. Does the same part come again, or does it change by a step each time? In the picture, the row of beads repeats.
- e.g. 1, 2, 1, 2, 1, 2 repeats.
- e.g. 1, 2, 3, 4, 5, 6 grows.
- e.g. 6, 5, 4, 3, 2, 1 shrinks.
### Number patterns in the sky and in your day · *defined*
**Definition:** Many things around us go up or down in steps. Some keep exactly the same step. Some only roughly.

Your age is a 'one more' pattern: you were 5, you are 6, you will be 7. The days left until a festival are a 'one fewer' pattern: 3 days, 2 days, 1 day, today. These steps are exact, because people count them. Now look at the Moon. After the new moon, the bright part grows a little each night for about two weeks. Then it shrinks a little each night for about two weeks. But it does not change by exactly the same amount each night. The tidy rule, the same step every time, belongs to counting.
- e.g. A lift going up shows 1, 2, 3, 4.
- e.g. A countdown before a rocket leaves Sriharikota: 5, 4, 3, 2, 1, 0.
- e.g. The Moon: thin, then a little wider each night until full, then a little thinner each night.
### A teak tree and a coconut palm keep a pattern too · *debated*
Cut across the trunk of a teak tree and you see rings, one inside the other. A teak tree grows fast in the rains and very slowly in the dry months. That makes one ring of wood each year. So a teak who is 10 years old has about 10 rings, and one who is 30 has about 30. Scientists in India count teak rings to learn about the rains of long ago. A coconut palm opens about one new leaf each month, 12 to 14 in a year. Each old leaf leaves a ring-shaped scar on the trunk when it falls. People do not agree on what to call this.
- e.g. One more year, one more ring: 1, 2, 3, 4.
- e.g. In a very odd year a teak can make an extra ring, so scientists check many trees against each other.
- e.g. A coconut palm with poor soil or little water opens fewer leaves in a year.
- **The view that the tree is keeping the pattern:** A tree senses the rains and the dry months, and grows or rests in answer. Year after year they add one ring. The tree is doing something step by step, in their own body. It is a number pattern made without number words.
- **Many plant scientists:** A ring is a mark left by the seasons. The tree is not counting anything. People count the rings afterwards. And the pattern is rough: a ring can be wide or thin, and now and then there is one too many or one too few.
### Stretch: when the step itself grows · *defined*
**Definition:** In some patterns the step is not the same each time. The step has a pattern of its own.

Build a staircase of chana with rows of 1, 2, 3 and 4. After each row, count all the chana so far. The totals go 1, 3, 6, 10. Look at the steps between them: two more, then three more, then four more. The step grows by one each time. So the next total is five more than 10, which is 15. About 1,500 years ago the Indian mathematician Aryabhata wrote down a quick rule for adding numbers that go up in equal steps.
- e.g. 1, 3, 6, 10, 15: the steps are 2, 3, 4, 5.
- e.g. Ten bowling pins stand in rows of 1, 2, 3 and 4.
- e.g. 1, 2, 4, 7, 11: the steps are 1, 2, 3, 4.

## Mostly agreed
- If you know where a pattern starts and what its rule is, you can work out every number in it. *How we know:* Anyone can test it. Tell two people 'start at 3, two more each time'. Both will write 3, 5, 7, 9, without seeing each other's paper.
- When you count 1, 2, 3, 4, you are making a number pattern. Its rule is one more each time. *How we know:* Lay chana in rows as you count. Each row is one longer than the row before. That is the staircase.
- If you start at 2 and go up by two each time, you never land on 1, 3, 5 or 7. *How we know:* Hop it on a number track with a button. The button jumps over every second box, and it is always the same boxes.
- A teak tree usually adds one ring of wood each year. *How we know:* A forester named Dietrich Brandis reported yearly rings in teak in 1879. Scientists in India still use teak rings to work out which years were dry and which were wet.

## How we found out
**Nore Wijns, Joke Torbeyns, Merel Bakker, Bert De Smedt and Lieven Verschaffel, 2019.** For many years, when researchers studied small children and patterns, they nearly always used repeating patterns, such as red, blue, red, blue. Patterns that grow, such as one block, two blocks, three blocks, were hardly studied at this age. So very little was known about what young children make of them. In 2019 Nore Wijns and four other researchers at the University of Leuven in Belgium set out to fill this gap. They worked with 400 four-year-olds, one child at a time. Each child was given both kinds of pattern, repeating and growing. The child was asked to carry a pattern on, to make the same pattern with other things, and to show how the pattern was built. The researchers also gave each child eight number tasks. They found that the kind of pattern and the kind of task both changed how well the children did. They also found that children who did well on most of the pattern tasks tended to do well with numbers. Growing patterns are now studied alongside repeating ones.  
*What people believed before:* For small children, the only patterns worth studying are repeating patterns. The 2019 study showed this was too narrow. Four-year-olds could work on growing patterns too, and how they did on patterns went together with how they did with numbers.

## Challenging perspectives
- **To find the tenth number in a pattern, you must write out all nine numbers before it.** (Many children and grown-ups; *rejected*)  
  For: Writing them all out always works, and it is the safest way when a pattern is new to you.  
  Against: Often the rule gives a short cut. In 1, 2, 3, 4 the tenth number is simply 10. In 2, 4, 6, 8 the tenth number is ten twos, which is 20. Mathematicians look for short cuts like these.
- **If a pattern begins 2, 4, the next number must be 6.** (Most worksheets; *debated*)  
  For: Two more each time is the simplest rule that fits, and it is what most people mean.  
  Against: Another rule fits too. Add the number to itself each time: 2 and 2 is 4, and 4 and 4 is 8. With that rule, 8 comes next. Two numbers fit more than one rule. That is why you check more pairs.
- **Nature follows number rules exactly.** (An old idea, held by many people who love maths; *debated*)  
  For: A teak tree adds a ring a year. The Moon grows and shrinks on time, month after month. Rules like these let people make calendars.  
  Against: Look closely and the steps are never exactly the same. Rings are wide in wet years and thin in dry years. The Moon's bright part does not grow by the same amount each night. The exact rule is in our counting. Nature comes close to it.

## Roots
We built staircases of chana and hopped along a number track. Now let us think about what one small step can do.

**Deep truth.** In the Staircase Test, each row had only one more chana than the row before. One chana is a very small change. But you kept to the same rule, and row 7 had seven. No row made a big jump. A big number can come from one small step, done again and again.  
*Habit it breaks:* When we see something big, we think something big must have made it. We forget the small steps underneath. And the tidy rule, the same step every time, is ours. We chose it and we kept to it.  
*Evidence:* In the Staircase Test, the first row had 1 chana and the seventh had 7, and every row added only 1. With two more each time, the fifth row already had 10.

- *who am i:* You were once small enough to sleep on one arm. You did not grow in one big jump. You grew a tiny bit each day, too little for anyone to see.
- *what is life:* A teak tree adds one thin ring of wood each year. A coconut palm opens about one new leaf each month. Living beings build themselves one small step at a time.
- *what is this world:* The Moon shows a little more of its bright face each night, for about two weeks. Then it shows a little less each night. The sky has growing and shrinking patterns too.

Start with an empty floor. Put down one chana. Then one more, and one more. Every number you know is made this way, from one small step done again and again. Change the step to two, and the same start gives a different staircase.

- **Dhammapada 122:** The Buddha says: do not think little of a small good deed. A water pot is filled drop by drop. In the same way, a wise person fills up with good, little by little. (A drop is 'one more each time'. Your staircase reached 7 in the same way, one chana at a time.)
- **Tao Te Ching 64:** The Tao Te Ching says: a tower nine storeys high begins as a heap of earth. A journey of a thousand li begins under your feet. A li is an old Chinese measure, about half a kilometre. (The tower and the journey are both made of small steps that are the same. That is a growing pattern.)
- **Tamil proverb: Siru thuli peru vellam:** An old Tamil saying goes: small drops make a great flood. (Anyone who has watched the monsoon fill a street has seen it. A flood is one drop more, a great many times.)
- Maths (settled): A child of about six grows roughly 6 centimetres taller in a year. Spread over the days, that is less than a quarter of a millimetre a day. Nobody can see one day's growth. Everyone can see a year's.
- Maths (open): Is the rule 'one more each time' out in the world, or did people make it to describe the world? Thinkers still argue about this.
- Other view, Many scientists who study how things change: They say this is only half the story. Some big changes are sudden. A balloon pops. A glass falls and breaks. And real things almost never add exactly the same amount each time. A teak tree makes a wide ring in a wet year and a thin ring in a dry year. They say the neat rule is in our maths, and the tree only comes close to it.
- Practice, A breath that grows and shrinks (3 min): Sit still and close your eyes. Breathe in while I count to 1, and breathe out. Now breathe in while I count 1, 2. Next breath, 1, 2, 3. Then 4. Now we come back down: 3, then 2, then 1. Open your eyes. Which breath felt the biggest? Did any breath make a big jump from the one before?
- Ask: You are taller than last year. On which day did you grow?
- Ask: Is 'one more each time' in the chana, or in the one who lays them down?
- Ask: What is something big that was made by many small steps? What is something big that happened all at once?
- Ask: Does a staircase of numbers ever have a last step?

## Deep and big questions
- *deep:* You know step 100 of the 'one more' staircase has 100 chana. Nobody has built it. How can you know? (hint: What does the rule tell you about every step?)
- *deep:* Is there a last number in the pattern 2, 4, 6, 8? (hint: Take the biggest one you can say. Can you add two?)
- *deep:* Can a pattern go down for ever, the way it can go up for ever? (hint: With chana it stops at none. Ask a grown-up about the numbers on a very cold thermometer.)
- *big:* You are taller than you were last year. On which day did it happen? (hint: Was there one big day? Or many tiny ones?)
- *big:* A teak tree adds one ring each year. Is the tree doing maths? (hint: The tree has no number words. Does a pattern need words?)
- *big:* Who made the rule 'one more each time': people, or the world? (hint: Think of the chana staircase. Then think of the Moon.)

## Story: The Lamp That Went Out
*Nila, Kannan and their grandmother are made up. Karthigai Deepam is a real festival of lamps, kept in Tamil Nadu in the Tamil month of Karthigai, when families light rows of small clay lamps outside their homes.*

It was the evening of Karthigai Deepam, and the whole street smelled of oil and wicks.

Nila was seven. Her cousin Kannan was five, and he had come all the way from Coimbatore just for the lamps.

Paati had filled a big steel plate with small clay lamps. Each one had a little oil and a cotton wick.

"This year you two will do the front steps," Paati said. "I will do the kolam. Do not run with the lamps."

The house had six steps going down to the street. Nila stood on the top one and thought.

"I know," she said. "One lamp on the top step. Two on the next. Three on the next. All the way down."

"Why?" said Kannan.

"Because then it gets wider and wider, like a river of lights."

Kannan liked that. He put one lamp in the middle of the top step. Nila put two on the second step. Kannan put three on the third.

Then he ran back to the plate. "How many now?" he asked. "I have to count the steps again."

"You do not have to count anything," said Nila. "Last time was three. So now it is one more."

Kannan looked at his fingers. "Four?"

"Four."

He carried four lamps, two in each hand, walking like a very careful duck. Nila did the fifth step. Before she went to the plate she already knew she needed five.

"And the last step is mine," said Kannan. He did not ask how many. He stood still and thought. Then he took six.

Paati came with the long matchsticks and lit every lamp. The steps glowed, one, two, three, four, five, six, all the way down to the street.

"Now come and eat," said Paati.

They were halfway through the pori urundai when the wind came. It was a short, cold wind, the kind that comes before rain. The door banged. Out on the street, somebody shouted.

Nila and Kannan ran to the door. Most of the lamps were still burning. But it was dark now, and nobody could see the lamps themselves any more. They could only see the flames.

"Some went out," said Kannan. "I can feel it. It looks wrong."

"Which ones?" said Paati. She had the matchsticks ready. "I cannot go down feeling every lamp in the dark with my knees."

Kannan started to count all the flames from the top. "One, two, three, four, five..." He lost his place somewhere in the middle and began again.

Nila did not count them all. She looked at one step at a time.

"Top step, one flame. Good. Next step, two. Good. Next, three. Good." She stopped. "Next step, three."

"So?" said Kannan.

"So it cannot be three again. After three comes four. One lamp on the fourth step is out."

She went on. "Fifth step, five. Good. Last step..." She counted twice. "Four. It should be six. Two are out down there."

Paati looked at her for a moment. Then she went down slowly, holding the wall. On the fourth step she found one cold lamp at the end of the row. On the last step she found two.

She lit all three. The river of lights was whole again.

"How did you know where to look?" Paati asked, when she had climbed back up.

"The steps told me," said Nila. "Each one has to be one more than the one before. If it is not, something is missing there."

Kannan was looking down the steps with his head on one side.

"If we had a seventh step," he said, "it would need seven."

"We do not have a seventh step," said Paati.

"I know," said Kannan. "But it would."

Then the first drops of rain came, and all three of them ran to carry the lamps under the roof, six at a time.

**For the parent:** For the parent: a number pattern is more than a list. Once Nila knows the rule, one more each time, she knows how many lamps each step needs without counting from the top. The same rule shows her where something is wrong, because a step that breaks the rule stands out. And Kannan sees that the rule goes on past the steps that exist.

- Ask: How did Kannan know to take six lamps for the last step, without counting the steps?
- Ask: The fourth step had three flames. How did Nila know that was wrong?
- Ask: Kannan counted every flame from the top. Nila looked at one step at a time. Why was her way quicker?
- Ask: There is no seventh step. How can Kannan know how many lamps it would need?

### g1 · What Is My Rule? (10 min)
- **rules:** You need the number track from 0 to 20, a button and 10 chana for scoring. To make a track, draw 21 boxes in a row and write 0 to 20 in them.; Shuffle the rule cards and the start cards. Put them in two piles, face down.; On your turn you are the maker. Take one rule card and one start card. Look at them secretly.; Put the button on your start number. Hop it three times by your rule, saying nothing.; The other players say the next number, and then the rule. The first to get both right takes one chana.; If nobody is right, the maker hops once more and they try again.; The maker passes to the next player. The first player with 3 chana wins.; Playing alone: turn over one card from each pile. Say the first five numbers aloud. Then check by hopping the button.

  *Parent says:* Your turn. Read it out. What is missing? What is the rule?  
  *Child mode:* Play the game. Say the missing number and the rule each time.
  - Ask: The gap was the first number. How did you find it? (good: I found the rule from the others.; I went backwards one step.; I tried a number and checked.)
- **s4 (1 min)**  
  *Parent does:* 1. When the pile is gone, count the cards. 2. Ask each player to make up one gap card for someone else.  
  *Parent says:* Count your cards. Now make up a gap pattern for me to solve.  
  *Child mode:* Count your cards. Then make up a gap pattern for someone else.

## Experiments
### e1 · The Staircase Test: can you know a step before you build it? (25 min)
- **question:** If we know the first few rows of a staircase, can we know a later row before we build it?
- **predict:** Before each new row, guess: how many chana will it need? Why do you think so?
- **fair test:** We write the guess down before we build the row, so nobody can change it afterwards. We use chana that are all about the same size, and we line every row up on the left so the rows are easy to compare.
- **safety:** Keep chana, beans and buttons away from babies and toddlers, who could choke on them.
- **record:** A grown-up draws the table. For each staircase, write the guess and what was built. At the end, the child says what they found, and the grown-up writes it under the table.
- **results table:** The staircase so far | My guess for the next row | What we built
- **s1 (3 min)**  
  *Parent does:* 1. Spread the newspaper. 2. Lay a row of 1 chana. Under it lay a row of 2, then a row of 3. 3. Line the rows up on the left. 4. Say nothing about the rule. Ask what your child notices.  
  *Parent says:* Look at my rows. What do you notice? What is happening from one row to the next?  
  *Child mode:* Look at the rows of chana. What changes from one row to the next?
  - Ask: What do you notice? (good: It gets longer.; Each row has one more.; It looks like stairs.; 1, 2, 3.)
  - Note: Take any answer. Do not say the rule yet. If your child says 'it gets bigger', ask 'by how much?'
- **s2 (4 min)**  
  *Parent does:* 1. Ask for a guess for row 4, and the reason. Write the guess. 2. Your child builds row 4. 3. Do the same for row 5. 4. Now ask about row 7, without building row 6. Write the guess. 5. Build rows 6 and 7 to check.  
  *Parent says:* How many chana will the next row need? Why do you think so? Now, what about row 7?  
  *Child mode:* Guess how many the next row needs. Say why. Then build it and check.
  - Ask: Why did you guess that for row 7? (good: Row 5 has 5, so row 7 has 7.; It goes one more each time: 6, then 7.; The row number is how many.)
  - Note: Row 7 is the real test, because row 6 is not there to look at. Some children guess 6. Let the building show it.
- **s3 (4 min)**  
  *Parent does:* 1. Sweep the chana into a heap. 2. In a clear space lay rows of 2, 4 and 6. 3. Ask what is different this time. 4. Ask for a guess for the next row, and why. Write it. 5. Your child builds it. 6. Guess and build one more row.  
  *Parent says:* Here is a new staircase. What is different about it? How many will the next row need? Why?  
  *Child mode:* This staircase is new. Guess the next row. Say why. Then build it.
  - Ask: What is different about this staircase? (good: It goes up faster.; It is two more each time.; The steps are bigger.)
  - Note: The next rows are 8 and 10. A guess of 7 means your child is still using the old rule, one more. Building the row and laying it under the 6 shows the gap.
- **s4 (4 min)**  
  *Parent does:* 1. Sweep up again. 2. Lay a row of 9. Under it lay a row of 7, then a row of 5. 3. Ask what is happening now. 4. Ask for a guess for the next two rows, and why. Write the guesses. 5. Your child builds them.  
  *Parent says:* Now look at this one. What is happening? What will the next row be? And the one after?  
  *Child mode:* Look at these rows. Are they growing? Guess the next two rows. Then build them.
  - Ask: Can there be another row after the row of 1? Why? (good: No, you cannot take two from one.; There is only one left.; It stops.)
  - Note: The rows shrink by two: 9, 7, 5, 3, 1. A guess of 4 means one fewer, not two fewer. With chana the staircase must stop at 1.
- **s5 (4 min)**  
  *Parent does:* 1. Your child closes their eyes. 2. Build the 'one more' staircase again, rows 1 to 6. 3. Cover row 4 with the towel. 4. Your child opens their eyes and says how many are hidden, and why. 5. Lift the towel to check. 6. Swap: your child hides a row for you.  
  *Parent says:* One row is hiding under the towel. How many chana are under it? How do you know?  
  *Child mode:* One row is hiding. How many chana are in it? Say how you know. Then look.
  - Ask: How did you know without looking? (good: The row before has 3 and the row after has 5.; It is one more than 3.; It is the fourth row, so 4.)
  - Check: A staircase goes 1, 2, 3, then a hidden row, then 5. How many are in the hidden row? → **4**
- **s6 (3 min)**  
  *Parent does:* 1. Your child closes their eyes again. 2. Lay rows of 2, 4, 5 and 8. 3. Ask your child to find the row that breaks the rule. 4. Your child fixes it.  
  *Parent says:* I have made a mistake in one row. Which row is wrong? How can you tell? Fix it for me.  
  *Child mode:* One row is wrong. Find it. Say how you know. Then fix it.
  - Ask: How did you find the wrong row? (good: It only went up by one there.; After 4 comes 6, not 5.; The step was not the same.)
  - Note: The row of 5 should be 6. Your child adds one chana to it. Then every step is two.
- **s7 (3 min)**  
  *Parent does:* 1. Look at the table together. 2. Ask your child what they think, what they saw, and why. 3. Write their words under the table.  
  *Parent says:* Look at your guesses. How could you know row 7 before it was built? What did you need to know?  
  *Child mode:* Look at your table. How did you know a row before building it?
  - Ask: What do you think now? What did you see? Why do you think it is so? (good: If you know the rule you can tell the next one.; It was one more every time, so row 7 was 7.; When the rule was two more, my old guess was wrong.; You need to know how much it changes each time.)
  - Check: A staircase has rows of 2, 4 and 6. What do you need to know to build the next row? → **The rule: two more each time**

### a1 · Number Track: hop the pattern (12 min)
- **problem:** On a number track, 'two more each time' is a hop of two boxes. Where do the hops land?
- **safety:** Keep chana, beans and buttons away from babies and toddlers, who could choke on them.
- **record:** On paper, write the numbers you landed on for each pattern. Under each row, write the rule in words, such as 'two more each time'.
- **s1 (3 min)**  
  *Parent does:* 1. Rule 21 boxes in a row on the paper strip, each about two fingers wide. 2. Your child writes 0 to 20 in the boxes. 3. Put the button on 0.  
  *Parent says:* Let us make a track of numbers. Write 0 in the first box. What comes in the next box?  
  *Child mode:* Draw 21 boxes in a row. Write 0 to 20 in them. Put a button on 0.
  - Note: Help with the numbers from 11 to 20 if they are shaky. Saying them aloud together is enough.
- **s2 (3 min)**  
  *Parent does:* 1. Your child hops the button two boxes at a time from 0. 2. They leave one chana on each box they land on. 3. Stop at 10 and ask where the next hop will land. 4. Go on to 20. 5. Read the chana numbers aloud.  
  *Parent says:* Hop two boxes each time. Put a chana where you land. Before you hop from 10, tell me where you will land.  
  *Child mode:* Hop two boxes each time. Leave a chana where you land. Go to 20.
  - Ask: Look at the chana. What do you notice about the boxes with no chana? (good: Every other box is empty.; 1, 3, 5 have none.; There is one empty box in each gap.)
  - Note: The chana sit on 2, 4, 6, 8, 10, 12, 14, 16, 18 and 20.
- **s3 (3 min)**  
  *Parent does:* 1. Leave the chana where they are. 2. Put the button on 1. 3. Ask: if you hop in twos from 1, will you land on any chana? Why? 4. Your child hops and finds out.  
  *Parent says:* Now start on 1. Same rule, two more each time. Will you ever land on a chana? Why do you think so?  
  *Child mode:* Start on 1 now. Hop two each time. Will you land on a chana? Guess, then hop.
  - Ask: What numbers did you land on this time? (good: 1, 3, 5, 7, 9.; All the empty ones.; The ones I jumped over before.)
  - Note: From 1 the button lands on 1, 3, 5 and so on to 19, and never on a chana. The rule is the same and the start is different.
  - Check: You start on 1 and hop two boxes each time. Which numbers do you land on? → **3, 5, 7**
- **s4 (3 min)**  
  *Parent does:* 1. Take the chana off. 2. Put the button on 20. 3. Your child hops back one box at a time for five hops, saying each number. 4. Then they hop back two boxes at a time from 20 to 10.  
  *Parent says:* Now we go backwards. Start on 20 and hop back one each time. Then try two each time.  
  *Child mode:* Start on 20. Hop back one box each time. Then hop back two each time.
  - Ask: You hopped back in twos from 20. What numbers did you say? (good: 18, 16, 14, 12, 10.; The same ones as going up, but backwards.)
  - Note: Backwards in ones: 19, 18, 17, 16, 15. Backwards in twos: 18, 16, 14, 12, 10. Hopping back in twos is hard at first. Let the track do the work.
### a2 · Pattern Hunt: a book, the stairs and a countdown (10 min)
- **problem:** Where at home do numbers go up or down by the same step each time?
- **safety:** On real stairs, a grown-up stays beside the child, and the child holds the rail. Use floor tiles if your home has no stairs.
- **record:** Write the three patterns you found, one under the other. Beside each, write its rule.
- **s1 (4 min)**  
  *Parent does:* 1. Open the book near the start. 2. Your child reads the number on the right-hand page. 3. Turn one leaf and read the right-hand page again. 4. After three numbers, ask for a guess for the next one. 5. Write the numbers down.  
  *Parent says:* Read me the number on this side only. Turn the page. And now? What will the next one be? Why?  
  *Child mode:* Read the right-hand page number. Turn the page. Read again. Guess the next one.
  - Ask: What is the rule for the right-hand pages? (good: Two more each time.; It skips one number.; The skipped number is on the back.)
  - Note: In most books the right-hand pages go 1, 3, 5, 7. Each leaf has two sides, so the number jumps by two.
- **s2 (3 min) · grown-up needed**  
  *Parent does:* 1. Chalk the numbers 1 to 10 on ten stairs or ten floor tiles in a row. 2. Your child starts before number 1 and steps over one each time. 3. They say each number they land on.  
  *Parent says:* Step over one each time. Tell me the numbers you land on. Which ones did you step over?  
  *Child mode:* Step over one stair or tile each time. Say the numbers you land on.
  - Ask: Which numbers did you land on? (good: 2, 4, 6, 8, 10.)
  - Note: On real stairs, stay beside your child and have them hold the rail. Tiles on the floor work just as well.
- **s3 (3 min)**  
  *Parent does:* 1. Your child crouches down. 2. Count down together from 10 to 0, one number each second. 3. At zero your child jumps up. 4. Ask what the rule was. 5. Do it again from 10 in twos.  
  *Parent says:* Let us count down from 10. Jump at zero. What was the rule? Now let us count down in twos.  
  *Child mode:* Crouch down. Count back from 10 to 0. Jump at zero!
  - Ask: Which countdown had fewer numbers to say? Why? (good: The twos one.; Because the steps are bigger.; It gets to zero faster.)
  - Note: In twos the countdown is 10, 8, 6, 4, 2, 0. It has six numbers. In ones it has eleven.
  - Check: A countdown goes 10, 8, 6. What is the rule? → **Two fewer each time**
### a3 · Maths in life: the dots of a 7 to 1 kolam (15 min)
- **problem:** People who draw kolams often name a dot pattern by its numbers, such as '7 to 1'. What do the numbers tell them to do?
- **record:** Keep your paper, or take a photo of the floor. Beside each row, write how many dots it has.
- **s1 (3 min)**  
  *Parent does:* 1. Your child puts down 7 dots in a straight row, about a hand-width apart. 2. Say that the next row goes above it, with one dot left out at each end. 3. Ask how many dots that row will have, before putting any down.  
  *Parent says:* Here is the middle row of 7. The next row leaves out one dot at each end. How many dots will it have? Why?  
  *Child mode:* Put 7 dots in a row. The next row drops one dot at each end. How many dots?
  - Ask: One dot fewer at each end. How many fewer is that in all? (good: Two fewer.; One and one is two.; 7, then 5.)
  - Note: The next row has 5 dots. One left out at each end makes two fewer in all.
- **s2 (4 min)**  
  *Parent does:* 1. Your child puts the row of 5 above the 7, each dot straight above a dot below. 2. Ask for the next row, and the next. 3. Your child puts down the rows of 3 and 1.  
  *Parent says:* After 7 came 5. What comes after 5? And then? Put them down.  
  *Child mode:* Put a row of 5 above the 7. What comes next? Put those rows down too.
  - Ask: Why is this kolam called '7 to 1'? (good: It starts at 7 and goes down to 1.; The rows go 7, 5, 3, 1.)
  - Check: The rows of dots go 7, 5, 3. How many dots are in the next row? → **1**
- **s3 (4 min)**  
  *Parent does:* 1. Your child does the same below the middle row: 5, then 3, then 1. 2. Read the rows from top to bottom together. 3. Ask where the pattern grows and where it shrinks.  
  *Parent says:* Now the same below. Read me all the rows from the top. Where does it grow? Where does it shrink?  
  *Child mode:* Put rows of 5, 3 and 1 below the 7. Read all the rows from the top.
  - Ask: Read the rows from the top. What do you notice? (good: 1, 3, 5, 7, 5, 3, 1.; It grows and then shrinks.; It is the same from the top and from the bottom.)
  - Note: From the top the rows go 1, 3, 5, 7, 5, 3, 1. They grow by two up to the middle, then shrink by two.
- **s4 (4 min)**  
  *Parent does:* 1. Your child joins the dots in any way they like, or loops a line around them. 2. If someone nearby draws kolams, ask them to show a '7 to 1' kolam, or one with other numbers. 3. Ask how they remember where the dots go.  
  *Parent says:* Now make it yours. Join the dots or loop around them. Let us ask how a kolam is remembered.  
  *Child mode:* Join the dots your own way. Ask someone how they remember a kolam.
  - Note: Many people remember a kolam by its dot numbers alone. Other kolams are '5 to 1' or '9 to 1'. Some use rows that shrink by one, with the dots set in the gaps of the row below.
### a4 · Maths in life: a chant that grows and shrinks (10 min)
- **problem:** Can a pattern grow in sound, the way a staircase grows in chana?
- **safety:** Keep chana, beans and buttons away from babies and toddlers, who could choke on them.
- **record:** Draw a dot for each beat of each line, one line under the other. Your drawing should look like a staircase.
- **s1 (3 min)**  
  *Parent does:* 1. Sit facing your child. 2. Say each line slowly with one clap for each sound. Line 1: ta. Line 2: ta ka. Line 3: ta ki ta. Line 4: ta ka di mi. 3. Your child copies each line after you.  
  *Parent says:* Listen and copy me. Ta. Ta ka. Ta ki ta. Ta ka di mi. How many claps was each line?  
  *Child mode:* Say and clap each line. Ta. Ta ka. Ta ki ta. Ta ka di mi.
  - Ask: How many claps were in each line? (good: 1, 2, 3, 4.; One more each time.)
  - Note: These sounds are real. South Indian drummers and dancers use them to say rhythms aloud. One clap for each sound is all that matters here.
- **s2 (3 min)**  
  *Parent does:* 1. Say the chant again. 2. This time your child lays one chana for each clap, a new row for each line. 3. Ask what the rows look like.  
  *Parent says:* Say it again, and put down one chana for each clap. Start a new row for each line. What does it look like?  
  *Child mode:* Say the chant again. Put one chana for each clap. Start a new row each line.
  - Ask: What do the rows of chana look like? (good: A staircase.; The same as the Staircase Test.; 1, 2, 3, 4.)
- **s3 (4 min)**  
  *Parent does:* 1. Now say the lines from the longest to the shortest: four claps, three, two, one. 2. Then say the whole thing up and down without stopping. 3. Ask whether the pattern is growing, shrinking or repeating.  
  *Parent says:* Now backwards. Ta ka di mi. Ta ki ta. Ta ka. Ta. Is that growing or shrinking? What is the rule?  
  *Child mode:* Now start with the long line. End with one clap. Is it growing or shrinking?
  - Ask: What is the rule when we say it backwards? (good: One fewer each time.; It shrinks by one.)
  - Note: A famous song does the same with words. In 'Tyagaraja Yoga Vaibhavam' by Muthuswami Dikshitar, the first line is sung again and again, a little shorter each time, until only 'vam' is left. Musicians call this shape gopuccha, the cow's tail. Later in the song a line grows instead.
  - Check: You clap 1 time, then 2 times, then 3 times. How many claps come next? → **4**

### p1 · The One-More Jar: five days (25 min, 5 days)
- **problem:** If you add one more than yesterday each day, how fast does a jar fill?
- **safety:** Keep chana, beans and buttons away from babies and toddlers, who could choke on them.
- **record:** The sheet of paper is the record. Each day has one row of dots, and the rows make a staircase. Beside each row, write the day's number and the total in the jar.
- **schedule:** day 1: Put 1 chana in the jar. Draw 1 dot on the paper. Guess tomorrow's number. (5 min); day 2: Put in 2 chana. Draw a row of 2 dots under yesterday's row. Guess tomorrow's number. (5 min); day 3: Put in 3 chana and draw a row of 3 dots. Guess how many are in the jar altogether, then tip them out and count. (5 min); day 4: Put in 4 chana and draw the row. Guess the total again before counting. (5 min); day 5: Put in 5 chana and draw the row. Guess the total, count, and say what days 6 and 7 would need. (5 min)
- **s1 (5 min)**  
  *Parent does:* 1. Your child puts 1 chana in the jar and draws 1 dot at the top of the paper. 2. Say that each day gets one more than the day before. 3. Ask for tomorrow's number and write the guess.  
  *Parent says:* Today the jar gets 1. Each day it gets one more than the day before. How many will it get tomorrow?  
  *Child mode:* Put 1 chana in the jar. Draw 1 dot. How many go in tomorrow?
- **s2 (15 min)**  
  *Parent does:* 1. On days 2, 3 and 4, your child puts in that day's number and draws that day's row. 2. From day 3, ask for a guess of the total in the jar before counting. 3. Tip the chana out, count them, and put them back. 4. Write the total beside the row.  
  *Parent says:* What is today's number? Put them in. Now guess: how many are in the jar altogether? Tip them out and count.  
  *Child mode:* Put in today's number. Draw the row. Guess the total. Then tip them out and count.
  - Ask: Is the total going up by the same amount each day? (good: No, it goes up by more each day.; First 2 more, then 3 more, then 4 more.)
  - Note: The totals are 1, 3, 6 and 10. The day's number grows by one. The total grows by a bigger step each day.
  - Wait: Do this on each of the next three days.
- **s3 (5 min)**  
  *Parent does:* 1. On day 5, your child puts in 5 chana and draws the row. 2. Ask for a guess of the total, then count. 3. Ask what days 6 and 7 would need. 4. Look at the staircase of dots together.  
  *Parent says:* Last day. How many today? How many in the jar now? What would day 6 need? And day 7?  
  *Child mode:* Put in 5 chana. Guess the total, then count. What would day 6 need?
  - Ask: On which day did the jar get the most? Was any day a big jump from the day before? (good: Day 5 got the most.; No, each day was only one more.)
  - Note: After day 5 the jar holds 15: that is 1 and 2 and 3 and 4 and 5. Days 6 and 7 would need 6 and 7.
  - Check: A jar gets 1 chana on day 1, 2 on day 2 and 3 on day 3. How many does it get on day 6? → **6**

## Challenges
### c1 · Stretch: how many chana make the whole staircase? (20 min)
- **problem:** A staircase has rows of 1, 2, 3 and so on. How many chana does a staircase of 4 rows use altogether? And 5 rows? Find a quick way to know the next total without counting every chana again.
- **your turn:** Now find your own quick way to get the next total. Use it to say how many chana a staircase of 6 rows needs. You do not have enough chana to build it, so explain how you know.
- **constraints:** Every staircase starts with a row of 1 and grows by one each row.; You have only 20 chana.; You must say the total for the next staircase before you build it.
- **general:** Build each staircase and count every chana from 1.; Keep the last total and count on for the new row.; Write the totals in a row and look for the rule between them.
- **creative:** Build two staircases of the same size and fit them together. They make a block of equal rows that is easy to count. Half of the block is one staircase.; Look at the steps between the totals: 2, 3, 4, 5. The step is the number of the new row.; Draw the staircases on squared paper and colour each new row in a new colour.
- **s1 (4 min)**  
  *Parent does:* 1. Your child builds a staircase of 3 rows: 1, 2, 3. 2. They count all the chana. 3. They add a row of 4 and count again. 4. Write the totals: 1 row, 2 rows, 3 rows, 4 rows.  
  *Parent says:* Build a staircase of three rows. How many chana in all? Add the next row. How many now?  
  *Child mode:* Build rows of 1, 2 and 3. Count all the chana. Add a row of 4. Count again.
  - Note: The totals are 1, then 3, then 6, then 10.
- **s2 (5 min)**  
  *Parent does:* 1. Point at the totals 1, 3, 6, 10. 2. Ask whether this is a 'one more' or a 'two more' pattern. 3. Ask how big each step is. 4. Ask for a guess for a staircase of 5 rows. Write it. 5. Your child builds it to check.  
  *Parent says:* Look at the totals: 1, 3, 6, 10. Is the step the same each time? What will the total be with 5 rows? Why?  
  *Child mode:* Look at 1, 3, 6, 10. Is the step the same each time? Guess the next total.
  - Ask: How big is each step between the totals? (good: 2, then 3, then 4.; It gets one bigger each time.; It is the same as the new row.)
  - Note: A staircase of 5 rows uses 15 chana. The step between totals is the size of the new row.
  - Check: The totals go 1, 3, 6, 10. What comes next? → **15**
- **s3 (6 min)**  
  *Parent does:* 1. Ask: with 20 chana, can you build a staircase that uses every chana? 2. Your child tries. 3. Then show one creative idea if they want it: build two staircases of 3 rows and fit them into a block.  
  *Parent says:* You have 20 chana. Can you make a staircase with none left over? Try it.  
  *Child mode:* Use all 20 chana in one staircase. Can it be done? Try.
  - Ask: What happened with 20? (good: 5 rows uses 15 and there are 5 left.; The next row needs 6 and I only have 5.; It cannot be done.)
  - Note: It cannot be done. Five rows use 15, and the sixth row needs 6 more, which makes 21. Two staircases of 3 rows fit into a block of 3 rows of 4, which is 12. Half of 12 is 6.
- **s4 (5 min)**  
  *Parent does:* 1. Ask your child to say how many a staircase of 6 rows needs, and how they know. 2. Write their way of working it out. 3. Ask what a staircase of 7 rows would need.  
  *Parent says:* You cannot build 6 rows with 20 chana. So tell me: how many would it need? How do you know?  
  *Child mode:* How many chana for 6 rows? You cannot build it. Say how you know.
  - Ask: How many for 6 rows? And for 7? (good: 21, because 15 and 6 more.; 28, because 21 and 7 more.)
  - Note: Six rows need 21. Seven rows need 28. Any way of explaining that uses the growing step is a good one.

## Worksheets
### What Comes Next? (core) (core, 12 questions)
1. (mcq) Look at the rows of dots. How many dots will the next row have?  
   Options: 3 / 4 / 5  
   **Answer:** 4. *Why:* 4. Each row has one more dot than the row above. One more than 3 is 4.
2. (fill) What comes next? 6, 7, 8, ____  
   **Answer:** ['9', 'nine']. *Why:* The rule is one more each time. One more than 8 is 9.
3. (fill) What comes next? 2, 4, 6, ____  
   **Answer:** ['8', 'eight']. *Why:* The rule is two more each time. Two more than 6 is 8.
4. (mcq) What comes next in this pattern?  
   Options: 7 / 9 / 6  
   **Answer:** 7. *Why:* 7. The numbers go down by one each time. One fewer than 8 is 7. Picking 9 means going up, not down.
5. (truefalse) In 1, 2, 3, 4 the rule is one more each time.  
   **Answer:** True. *Why:* True. From 1 to 2 is one more. So is 2 to 3, and 3 to 4.
6. (mcq) What is the rule of the pattern 5, 7, 9?  
   Options: One more each time / Two more each time / Two fewer each time  
   **Answer:** Two more each time. *Why:* Two more each time. On the number track, 5 to 7 is two hops, and 7 to 9 is two hops.
7. (fill) What is missing? 4, 5, ____, 7  
   **Answer:** ['6', 'six']. *Why:* The rule is one more each time. One more than 5 is 6, and one more than 6 is 7, so 6 fits.

   **Answer:** 1, 2, 3, 4 → Growing; 9, 8, 7, 6 → Shrinking; 2, 4, 6, 8 → Growing; 10, 8, 6, 4 → Shrinking; 5, 6, 7, 8 → Growing; 7, 6, 5, 4 → Shrinking. *Why:* In a growing pattern each number is bigger than the one before. In a shrinking pattern each number is smaller.

   **Answer:** 3, 4, 5, 6 → one more each time; 3, 5, 7, 9 → two more each time; 9, 8, 7, 6 → one fewer each time; 9, 7, 5, 3 → two fewer each time. *Why:* Look at two numbers side by side. Ask whether it went up or down, and by how much.

## Quiz
1. (mcq) What comes next in this number pattern?  
   Options: 9 / 10 / 11  
   **Answer:** 10. *Why:* 10. The rule is one more each time. One more than 9 is 10.
2. (fill) Look at the rows of dots: 4, 6, 8. The next row has ____ dots.  
   **Answer:** ['10', 'ten']. *Why:* The rule is two more each time. Two more than 8 is 10.
3. (mcq) What comes next? 15, 14, 13  
   Options: 14 / 12 / 11  
   **Answer:** 12. *Why:* 12. The numbers go down by one each time. One fewer than 13 is 12.
4. (fill) What comes next? 16, 14, 12, ____  
   **Answer:** ['10', 'ten']. *Why:* The rule is two fewer each time. Two fewer than 12 is 10.
5. (mcq) What is the rule of the pattern 3, 5, 7, 9?  
   Options: One more each time / Two more each time / Three more each time  
   **Answer:** Two more each time. *Why:* Two more each time. From 3 to 5 is two hops on the number track, and so is every other step. Picking 'three more' often comes from reading the first number, 3, as the rule.
6. (mcq) Which pattern follows the rule 'one fewer each time'?  
   Options: 5, 6, 7 / 9, 8, 7 / 8, 6, 4  
   **Answer:** 9, 8, 7. *Why:* 9, 8, 7. Each number is one fewer than the one before. 5, 6, 7 goes up. 8, 6, 4 goes down by two.
7. (fill) What is missing? 8, ____, 10, 11  
   **Answer:** ['9', 'nine']. *Why:* From 10 to 11 is one more, so the rule is one more. One more than 8 is 9.
8. (mcq) This staircase should grow by two each time. Which row has the wrong number of dots?  
   Options: the row of 4 / the row of 7 / the row of 8  
   **Answer:** the row of 7. *Why:* The row of 7. Two more than 4 is 6, so that row should have 6 dots. Then two more than 6 is 8, which fits.
9. (mcq) Which rule built this staircase of dots?  
   Options: One more each time / Two more each time / Two fewer each time  
   **Answer:** Two more each time. *Why:* Two more each time. The rows have 1, 3 and 5 dots. Each row is two longer than the row above.
10. (mcq) A button starts on 4. It hops two more, two times. Where does it land?  
   Options: 6 / 8 / 10  
   **Answer:** 8. *Why:* 8. The first hop lands on 6 and the second on 8. Picking 6 means making only one hop.
11. (mcq) You clap once, then twice, then three times, then four times. What kind of pattern is it?  
   Options: Growing / Shrinking / Repeating  
   **Answer:** Growing. *Why:* Growing. Each turn has one clap more than the turn before. Nothing comes round again the same, so it is not a repeating pattern.
12. (truefalse) 1, 2, 1, 2, 1, 2 is a growing pattern.  
   **Answer:** False. *Why:* False. The part 1, 2 comes again and again. It is a repeating pattern. A growing pattern would go on to 3.

## Applications
- A person saving money puts the same amount in a box each week. The total grows in equal steps.
- A builder makes every stair the same height. People would trip if the step changed.
- A calendar counts the days of a month: one more each day.
- Before a rocket leaves Sriharikota, the countdown goes one fewer each second.
- A person knitting a cap makes each round a few stitches smaller, so that the top closes.
- A kolam is laid out with rows of dots that grow and shrink by the same number each time.
- A bus conductor's tickets are numbered one more each time, so a missing ticket shows up.
- Scientists count the rings of a teak tree, one for each year, to find out how old the wood is.

## Spotted around us
- The steps of a Golu at Navaratri, where dolls are set out on steps. Families use an odd number of steps: 3, 5, 7, 9 or 11. That is two more each time.
- A dot kolam at a doorstep. Count the dots in each row from the middle outwards. Often they go 7, 5, 3, 1.
- The page numbers of a book. Look only at the right-hand pages. In most books they go 1, 3, 5, 7.
- The floor numbers in a lift. Going up they show one more each time. Going down they show one fewer.
- Everyone does maths: a teak tree. Look at the cut end of a teak log at a timber yard, or at an old wooden beam. Each ring is about one year of the tree's life.
- Everyone does maths: a coconut palm. The trunk has ring-shaped scars, one for each leaf that fell. A healthy palm opens about one new leaf a month.
- The Moon. Look every evening for two weeks after the new moon. The bright part gets a little bigger each night.
- A stack of steel vessels in the kitchen, each one a little smaller than the one below, so that they fit inside each other.

## Open questions
- **Do other animals notice a rule like 'one more each time'?** Tests show that some animals keep track of small numbers. Whether any of them notice that a row of numbers follows a rule is much harder to test, and nobody knows yet.
- **How does a teak tree keep time?** A teak's rings follow the wet and dry seasons. Scientists are still working out what happens inside the tree to start and stop the growing each year.
- **Is there a simple rule for the numbers 2, 3, 5, 7, 11, 13?** These are the numbers that cannot be shared out into equal groups, except in ones. They are called prime numbers. People have looked for more than two thousand years, and nobody has found a simple rule that gives the next one.
- **Why does a plain rule like 'the same step each time' fit so many different things?** Stairs, ages, tree rings and savings all follow it, at least roughly. Thinkers do not agree on why maths fits the world so well.

## Connected maths
- Lamps stand on the steps of a house. The top step has 1 lamp, the next has 2, the next 3, the next 4. How many lamps does step 6 need? **6 lamps.**. The rule is one more each step. Step 5 needs 5. Step 6 needs one more than that, which is 6. (queues `math.number-sense.counting.L1`)
- A button is on 3 on the number track. It hops two more, four times. Which numbers does it land on? Where does it end? **5, 7, 9, 11. It ends on 11.**. Two more than 3 is 5. Then 7, then 9, then 11. Four hops, so four numbers after the start. (queues `math.addition-subtraction.meaning.L1`)
- A tin holds 12 murukkus. The family eats 2 each day. How many are left after 3 days? On which day is the tin empty? **6 are left after 3 days. The tin is empty on day 6.**. The rule is two fewer each day: 12, 10, 8, 6. That is 3 days. Carry on: 4, 2, 0. That is 3 more days, so day 6. (queues `math.patterns.number-patterns.L2`)
- The top half of a kolam has rows of 7, 5, 3 and 1 dots. How many dots is that altogether? **16 dots.**. Add the rows. 7 and 5 is 12. 12 and 3 is 15. 15 and 1 is 16. (queues `math.addition-subtraction.number-facts.L1`)
- Someone copied the right-hand page numbers of a book: 1, 3, 5, 8, 9. One number is wrong. Which one, and what should it be? **The 8 is wrong. It should be 7.**. The rule is two more each time. Two more than 5 is 7, not 8. And two more than 7 is 9, which fits the last number. (queues `math.patterns.number-patterns.L2`)
